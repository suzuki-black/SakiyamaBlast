# 面エディタ

盤面を手で置いて、**その場で採点を回す**道具。ブラウザで開く。

```sh
make editor
```

`http://127.0.0.1:8765/?t=…` が開く。止めるのは Ctrl-C。

---

## 何をする道具か

```
   置く  ──▶  面データ  ──▶  sim / metrics.py / emotion.py  ──▶  合否と指標
    ▲                                                              │
    └──────────────────── 直す ────────────────────────────────────┘
```

**採点の規則はこの道具に入っていない。** `metrics.py` と `emotion.py` を
そのまま呼び、返ってきた合格条件と値を並べるだけ。しきい値を写し取ると、
片方を直した日に静かに食い違うため（`metrics.py` の `GATES` が唯一の正）。

**盤面の整合もこの道具は判定しない。** `sim --load` に読ませて、返ってきた
文句をそのまま下の帯に出す（`docs/STAGE_FORMAT.md` の検査が唯一の正）。
赤い帯が出ているあいだは採点を始めない。

### 腕を選ぶ（合否はこれで変わる）

**合否は面だけの性質ではない。遊び手の腕との組み合わせで決まる。**
面1 は同じ盤面のまま、腕を変えるだけで判定が裏返る（16回／面）。

| 腕 | 緊張感 | 爽快率 | クリア率 | 判定 |
|---|---|---|---|---|
| 貪欲 | 0.0 ×  | —（ヒヤリ0回なので出ない） | 1.0 | 不合格 |
| 先読み | 4.79 ○ | 0.94 ○ | 1.0 | **全部 ○** |

貪欲は寄り道をせず最短で炭へ行くので、面1 ではヒヤリが一度も起きない。
先読みは敵を読みながら回り道をするぶん、危険に近づいて自分で解消する。

**両方の表に同じ腕を渡している。** 片方を貪欲、片方を先読みで回すと、
並んだ2枚が別の遊び手の話になるため。見出しに腕を必ず書いてある。

## 使い方

1. **面番号**を選ぶ。盤面以外（敵の強さ・持ち時間・土の色）はこれで決まる
2. **生成から読む**で、いまの自動生成の面を下敷きにする（種を入れれば振り直せる）
3. 左の一覧から選んで盤面を**押すか引く**。**右押しで消す**
4. 下の帯が緑（○）なら**採点する**

| 操作 | |
|---|---|
| 左押し・引きずり | 置く |
| 右押し・引きずり | 消す |
| `1`〜`9` `0` `-` | 黒ダイヤの耐久を 1〜9 / 10 / 11 に |
| Ctrl-Z | 戻す |

**一点物（出発点・巣・風呂・湧き出し口・ガス）は引きずらない。** 通った升
ぜんぶに置いても困るだけなので、押した升にだけ効く。

### 置くと勝手に揃うもの

手で矛盾を作りにくいように、置いた時点で辻褄を合わせている。

| 置いたもの | 一緒にすること |
|---|---|
| 黒ダイヤ・炭柱 | その升を**土**にする（黒ダイヤは土の中にある） |
| 割れた黒ダイヤ・樋・火薬・溜まり湯 | その升を**坑道**にする |
| 出発点・巣・風呂・湧き出し口・ガス | その升を**坑道**にする |
| 炭柱を空の升へ | 黒ダイヤも一緒に置く（耐久は通常 +3。`place_pillars` と同じ） |
| 土で埋める | その升の**火薬と溜まり湯を外す**（どちらも坑道のもの）。炭柱は残す |

**岩だけは掘り済みかどうかを触らない。** 樋の落とし口の隣は掘られるので、
**岩が坑道の升に居ることが実際にある**（`docs/STAGE_FORMAT.md` §1.4）。

### 保存と読み込み

保存先は `tools/stage_editor/stages/`。名前は英数字と `_` `-` だけ、末尾は
`.json`。**中身は git で追跡していない**（試作が溜まるところなので）。

保存したものはコマンドラインからそのまま使える。

```sh
tools/hostsim/sim --load tools/stage_editor/stages/foo.json --board
python3 tools/hostsim/metrics.py --load tools/stage_editor/stages/foo.json --runs 24
```

**岩の並び順（`rockOrder`）は、指している升が変わらないあいだだけ持ち越す。**
岩を足したり消したりしたら落として、左上から読む順に任せる。落としたときは
保存の知らせにそう書く。

## 見た目について

盤面は本物の `assets/tiles.png` と `assets/sprites.png` をそのまま貼っている。
ただし**土と坑道は絵ではなく色で塗っている**（ゲーム側も `vdp_fill` と
`draw_grain` でそうしている）。**土の粒の散らし方は本物と違う**ので、
土かどうかを見分ける目安と思うこと。

幕ごとの土の色は `editor.py` の `DIRT_BY_ACT` にある。
**`src/levels.c` の `set_dirt_palette()` と必ず一致させること。**

黒ダイヤの耐久は升の左上に数で出す。**色の濃淡では出さない**（作者が色弱）。
合否も `○` `×` と明度で出していて、色相には意味を持たせていない。

## 中身

| ファイル | |
|---|---|
| `editor.py` | 裏方。ファイルを読み書きし、`sim` / `metrics.py` / `emotion.py` を呼ぶ |
| `index.html` `app.css` `app.js` | 画面 |
| `stages/` | 保存先（git では追跡しない） |

**127.0.0.1 にだけ開き、起動ごとの合図（token）を要求する。** 外から届かない
だけでは足りない ── ブラウザで開いている別のページが localhost へ投げてくる
形があるので、URL に入れた合図を見て弾く。この道具はファイルを書き、子プロセスを
起こすので、そこは締めてある。保存先は `stages/` の中に閉じ込めてあり、
子プロセスはすべて引数の配列で呼ぶ（シェルを通さない）。
