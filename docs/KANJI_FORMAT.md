# 漢字フォントの差し替え方（外部へ依頼するとき用）

面の開始に出す「第 X 階層 開始」の字は、`tools/mkkanji.py` の中に**ドット絵**として
書いてある。ここを描き替えて `make` すれば差し替わる。C のコードには触らなくてよい。

## 描いてほしいもの

| 字 | 状態 |
|---|---|
| 第 階 層 開 始 | **描き直してほしい**（いまのは実装側の一次案で、画数が多く潰れている） |
| 一 二 三 四 五 六 七 八 九 十 | 面番号に使う。こちらも直してよい |

## 形式

**16×16 の 1bpp。** `#` が字、`.` が余白。**16行ちょうど、各行16文字ちょうど。**
これ以外の文字は使えない（スクリプトが弾く）。

```python
G['第'] = [
"...##......##...",
"...##......##...",
"..####....####..",
"################",
"..##......##....",
"................",
".##############.",
".##..........##.",
".##############.",
".##..........##.",
".##############.",
"......####......",
"......#..#......",
"....######......",
"......##........",
".....##.........",
]
```

## 決まりごと

- **並び順は変えない。** `order = ['第','階','層','開','始','一',…,'十']` は
  `src/game.h` の `KJ_*` と一致している必要がある
- **1文字あたり32バイト**。15文字で480バイト。ROM のバンク側に置いてあり、
  いまの空きは約350バイトなので、**字数を増やすと入らない**
- 表示は 16×16 をそのまま等倍で出す。拡大や縮小はしない
- 色は字が1色、下地が1色。**アンチエイリアスや中間色は使えない**
- 字面の狙いは「古くさい写植のような重い線」。細い線は 16×16 では潰れる

## 確認のしかた

```bash
make            # 差し替えてビルド
make check      # 壊れていないか
```

画面での見え方は openMSX で VRAM を読めば確認できる（`docs/HOSTSIM.md` とは別に、
`debug read VRAM` で表示行 y=80..95 を見る）。

## いま出ている字（実装側の一次案）

`python3 tools/mkkanji.py` を実行すると C の配列が出る。ドット絵そのものを見るには
`tools/mkkanji.py` を直接開くのが早い。
