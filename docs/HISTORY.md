## 1. 先山とは何か

「先山」には2つの意味があり、昭和初期は (A) から (B) へ移る過渡期にあたる。

**(A) 作業単位の片割れとして** — 切羽（採炭現場）で直接石炭を掘る者を先山、
掘った石炭を運び出す者を後山と呼ぶ。先山1人と後山1〜2人で1つの労働単位を構成し、
後山は先山の指揮命令に従った。夫婦、あるいは父と娘で組み、夫または父が先山を
務めることが多かった。常磐でも坑内では後山夫のほか採炭夫・支柱夫、坑外では
選炭夫を女性が担った。

出典: 日本大百科全書（ニッポニカ）「先山・後山」／『家族社会学研究』33(2)　**確定**

**(B) 熟練者・現場指揮者として** — 先山は熟練作業員、後山は技量未熟な作業員を
指し、1つの作業箇所に先山1人と後山2〜3人が配され、先山の指示で作業が進んだ。
とくに円熟した技量を持つ先山を「大先山（おおさきやま）」、長壁式切羽を指揮する
大先山を「ロング長」と呼んだ。

出典: 日本大百科全書「炭鉱用語集」／NPO法人炭鉱の記憶推進事業団　**確定**

**主人公が1人で先山を名乗るのは (B) の意味で正しい。**

なお山本作兵衛の記録画に、つるはしを担ぎカンテラを提げた先山が**午前3時に入坑**
する様子が描かれている（出典: y-sakubei.com　**有力**）。主人公名「丹野3時」は
作者の祖父の実名「丹野三司」に由来するもので、この時刻とは無関係。ただし偶然の
一致として演出に使う余地はある。

## 2. 坑内の暑さと水 — 体温メーターの裏付け

**常磐は他の炭田と条件がまるで違い、それがそのまま体温メーターの根拠になる。**

- 硫黄分が多く純度の低い低品位炭。地層が激しい褶曲を受けているため、炭層を求めて
  地下へ掘り下げる高い掘削技術を要した
- 地下水が多く温泉も湧き出すため坑内は暑く過酷。当時世界最大級の排水ポンプを
  並べていた
- **40度もの地熱**と多い水量のため坑内労働は非常に過酷で、**採炭夫は塩をなめながら**
  働いていた
- 1950年代に取材した写真家によれば坑内は**気温40度・湿度98%**に達し、冷たい坑道から
  高温多湿の採掘場へ向かうとカメラが水に入れたように濡れた。男たちはふんどし姿で
  採掘していた

出典: Wikipedia「常磐炭田」／季刊『社会運動』433号（龍田光司氏談）／デイリー新潮
**有力**

### 2.1 坑内の水風呂 — 確定

**常磐炭鉱では坑内に水風呂があり、作業の合間に反復して入っていた。**

いわき市石炭・化石館「ほるる」の模擬坑道に、**炭鉱労働者が坑内で水風呂に入って
いる様子の展示**がある。同館学芸員・渡辺文久氏の解説によれば:

- 場所によっては石炭1トンを掘るのに**40トンの湯をくみ出す**必要があった
- 坑内は**気温40度弱、湿度100%**。学芸員はこれを「サウナ状態」と表現
- **15〜30分ほど働いたら水風呂に入り、梅干しを食べて塩分補給をした**

出典: 読売新聞 福島版 2026年4月30日「発掘！！おらほの旅① 炭鉱ツアーと博物館
（いわき市）」（新田健 記者）／ほるる模擬坑道の展示　**確定**

作者に家族から伝わっていた「水風呂」の話と、新聞記事および博物館展示が一致した。

**この確認によって、以前「坑内の湯は熱いので水風呂の裏付けが弱い」とした評価は
覆っている。** 湯本温泉が源泉枯渇後に坑内湧出の温泉供給を受けていたのは事実だが、
それは自然に湧く湯の話であり、坑内の水風呂の存在とは両立する。

### 2.2 現行仕様との対応（実装に合わせて訂正済み）

| 現行ルール | 史実上の位置づけ |
|---|---|
| 盤面に水風呂が1つある | **確定**。坑内の水風呂は実在。ほるるに展示あり |
| **何度でも入れる** | **確定**。15〜30分作業 → 入浴 の反復サイクル。1面1回に制限する改変は史実に反するので採らない |
| 体温 `TEMP_MAX 240`（約60秒）でオーバーヒート | 15〜30分に一度入らねば命に関わる、という実際の周期の圧縮 |
| **入っている間だけ `BATH_COOL` ずつ徐々に冷える** | **元資料は「通過すると一気に0へ戻る」を裏付けとしているが、それは 94e4f45 以前の挙動**。現行の「浸かった時間に比例して冷える」ほうが「15〜30分働いたら**入る**」というサイクルに忠実で、史実の裏付けはむしろ現行実装に強く効く |
| 風呂は落下してきた岩で壊れ、その面では復活しない | **有力**。坑内水は温泉で熱いため、冷水は坑外から引くか別系統だったはず（§9 未確認）。つまり水風呂は配管・設備に依存したインフラであり、「壊れるのは湯船ではなく系統」と解釈すれば整合する |

### 2.3 湧水量「4トン」と「40トン」

Wikipedia は記録映画に基づき「石炭1トンあたり地下水4トン」、別記述では「1トンを
掘るために40トンの湯を廃棄」としており10倍の開きがあった。読売記事の学芸員解説は
「**所によって**1トンの石炭を掘るのに40トン」としており、**坑や深度による場所差**
と理解するのが妥当。　**ほぼ解決**

## 3. 作業フローと現場の語彙

昭和初期の一般的な流れ: **穿孔 → 発破 → 浮石落とし → 支柱（枠入れ） →
積込・運搬 → 仕繰** の反復。大正期ごろから火薬による発破で採炭し、坑道の保持には
昭和初期までは木材を三ツ枠に組んで落石や落盤を防いだ。三池の例では操業24時間を
3分割し、朝入坑の「一番方」、昼の「二番方」、夜の「三番方」。番方は1週間ごとに
変わった。

### 転用できる語彙

| 語 | 意味 | 転用先 |
|---|---|---|
| 切羽（きりは）／引立（ひったて） | 掘削作業をしている先端 | 自機の掘り進み先 |
| 浮石（うきいし） | 亀裂で本体から剥がれ落ちかけた岩。支えるか人為的に落として除去 | **現在の「岩」そのもの** |
| 高落（たかお）ち | 落盤 | ミス演出の名称 |
| 落（ば）らす／落れる | 人為的に崩す／自然に崩れる | 岩を能動的に落とす操作の名前 |
| 残柱式・柱房式 | 幅7〜8mごとに切羽と炭柱に分け、天盤を支えるため炭柱を採掘せずに残す | **§5.1。「特殊な黒ダイヤ」TODO の答え** |

## 4. 危険性と事故

いわき市史・別巻『常磐炭田史』をもとにした事故一覧が公開されている
（ja.localwiki.org/iwaki「常磐炭鉱の災害(事故)一覧」）。種別ごとに数えると
常磐の危険は4つに分かれる。

| 種別 | 特徴 | 主な例 |
|---|---|---|
| **ガス爆発**（最多） | 原因欄に「喫煙」「カンテラの灯」「発破」が繰り返し出る | 大正13年8月 入山採炭第五坑南卸 死者75名／昭和10年5月 入山採炭第六坑 死者49名 |
| **坑内出水** | 常磐に特に多い。湧水量の多さの裏返し | 明治38年 茨城無煙炭鉱 死者8名・気絶28名／昭和13年 鳳城炭砿 死者9名 |
| **坑内火災** | 最悪の被害を出した種別 | 昭和2年3月 磐城炭砿内郷炭砿町田竪坑 死者134名（Wikipedia は救助隊の二次災害を含め131人。**数字に異同あり**） |
| **落盤・運搬事故** | 件数は多いが1件あたりの死者は少ない | 昭和30年 鹿島坑 死者6名／大正11年 人車巻上ロープ切断 死者16名 |

戦時期の悪化: 鉱山監督局の統計では常磐炭田の労災死亡者数は 1939年88人 → 40年116人
→ 44年131人 → 45年176人と倍増し、合計は800人近く（『いわき市史別巻 常磐炭田史』
508・511頁）。戦時動員された朝鮮人労働者の死亡者も含まれる。

**史実の脅威の重みはガス＞水＞熱＞落盤の順。** 現在のミス条件は「敵に触れる／
オーバーヒート／落岩」の3つで、最多のガスが入っていない。「原因＝カンテラの灯・
喫煙」という記録は**火とガスが同じ空間にあることが事故の条件だった**ことを示す。
升単位のゲームに落としやすい構造で、§5.2 の案につながる。

## 4b. じん肺と常磐じん肺訴訟

**本作にはゲーム要素として組み込まない（作者の決定。§8 参照）。** ただし炭鉱と
じん肺は法的にも社会的にも不可分であり、事実として正確に把握しておく。

### じん肺とは

じん肺法上は「粉じんを吸入することによって肺に生じた線維増殖性変化を主体とする
疾病」と定義される。粉じんが肺胞にたまり、肺が固くなって呼吸が困難になる病気で、
**一般に不可逆性であり、粉じん作業を止めた後も進行する。じん肺そのものについては
現在も治療の方法がない。** 肺炎等の感染症にかかりやすくなり、**肺がんなどの
合併症を引き起こす**ことがある。

出典: 経済産業省「石炭じん肺訴訟について」／厚生労働省 福井・奈良労働局　**確定**

管理区分の決定は退職から相当年数を経て下りることがあり（労災審査事例では、昭和31年
から掘進夫・採炭夫として粉じん作業に従事した被災者が平成11年に管理2の決定を受けた
記録がある。厚生労働省 令和元年労第218号）、**じん肺は現役中ではなく引退後に姿を
現す**病気である。

### 常磐じん肺訴訟（第1陣）

**1992年（平成4年）1月24日、全国初の大型集団訴訟の和解が成立している。**

いわき市の旧常磐炭鉱で働きじん肺症になった患者や遺族83人が、罹患したのは安全管理
への配慮が足りなかったためとして総額7億4600万円の損害賠償を求めた「常磐炭鉱じん肺
第1陣訴訟」の控訴審で、会社側が和解金として総額4億2000万円を支払うことで和解した。
提訴から約6年4カ月ぶりの決着で、**全国の大型集団訴訟での和解は全国で初めて**だった。

出典: 福島民報「福島県 今日は何の日」1992年1月24日
（https://www.minpo.jp/news/moredetail/2022011293532）　**確定**

**この訴訟が「全国初」だったという事実は重い。** 筑豊など他の炭田に先んじて、常磐の
元坑夫と遺族が集団で会社の責任を問い、会社がそれを認めて金銭を支払った。炭鉱労働の
被害が法的に承認された最初の事例が、この山で起きている。

### 全国の流れ

| 年 | 出来事 |
|---|---|
| 1985年12月 | 国を相手にした初の筑豊じん肺訴訟が提訴 |
| 1985年秋ごろ | 常磐炭鉱じん肺第1陣訴訟 提訴（1992年の和解から逆算） |
| **1992年1月24日** | **常磐じん肺訴訟第1陣 和解成立。大型集団訴訟の和解として全国初** |
| 2004年4月27日 | 筑豊じん肺訴訟最高裁判決。**国の規制権限の不行使が国家賠償法上違法**であることが確定 |
| 以降 | 令和2年1月末時点で原告患者2,245名に損害賠償金約170億円を支払い解決済み |

出典: 経済産業省 産業保安グループ石炭保安室「石炭じん肺訴訟の現状について」
（令和2年2月18日）／福岡県弁護士会筑豊部会　**確定**

常磐の和解（1992年、対会社）が先にあり、その12年後に最高裁が国の責任を認めた
（2004年）という順序になる。

**本資料は法的助言ではない。**

## 5. 史実 → ルールへの対応

ここは**案であって決定ではない**。採否と優先順位は `docs/DESIGN_PROPOSALS.md` を見ること。

### 5.1 残柱式採炭 ＝ 「特殊な黒ダイヤ」TODO の答え

柱房式は炭柱を残しつつ掘進して採炭し、数十m進んだところで残した炭柱を採掘しながら
後退する方法。**炭柱には通気のため所々に目抜きを設ける。**

「掘り尽くすべきか、支えを残すべきか」は炭鉱がずっと抱えていた実際の問題であり、
これは本作の**岩の支え判定と既に一致している**。黒ダイヤは未掘の升に置かれるため
`dug=0` で、そのまま岩の支えになっている（実測確認済み。DESIGN_PROPOSALS 参照）。

したがって「炭柱」とは**耐久が高く、絵が違い、岩の下に意図的に置かれた黒ダイヤ**
であればよく、新しい機構を要しない。

**ただし元資料が併せて提案する「クリア条件を全採掘から実収率○%以上へ変える」は、
作者が明示的に決めた全採掘条件と衝突するため採らない。**

### 5.2 通気とガス ＝ cell_link の第二の用途

炭鉱で一番怖いのは目に見えないメタンガスで、突然吹き出したり自然発火・爆発したり
する予測できない事故への備えが重要だった（NPO法人炭鉱の記憶推進事業団）。§4 の
事故一覧で原因欄に「カンテラの灯」「喫煙」が並ぶことと合わせて:

- 袋小路（**鉄砲坑道**）の升にガスが溜まっていく
- 溜まった升で発破（ダイナマイト）を使うと爆発してミス
- **目抜を掘って風を通せばガスが抜ける**

`cell_link[]` が既に升の連結を持ち、敵の経路計算に BFS を使っているので、扇風機の
坑口から幅優先で風が届く升を計算するだけで実装できる。内郷には坑内の空気を外へ
排出する巨大な扇風機のレンガ造り上屋が現存している（いわきヘリテージツーリズム
協議会）ので、盤面の隅に扇風機を置く絵的な根拠もある。

### 5.3 面の傾斜 ＝ 裏面（`loop_n`）の中身

常磐炭田の炭層は阿武隈高地東縁から海岸に向かって**7〜10度の角度で深部へ傾斜**して
おり、海岸へ近づくにつれて採炭条件が容易でなくなり、大手の炭鉱しか掘削できなく
なっていった（いわき市公式　**有力**）。

**「中身が無い」とされている裏面（2周目）の答えがこれ。** 周回するごとに海側の
深部へ進む。深くなるほど地熱が上がり、湧水が増える。土の色が3面ごとに変わる既存の
仕組みをそのまま深度の表現に使える。**難度パラメータをいじる理由が数字ではなく
地質になる**のが利点。

### 5.4 立坑（面と面の間）

作者が石炭化石館で購入した野木英雄『立坑独立愚連隊』が扱うのは**掘進**、立坑を下へ
掘り下げる仕事。採炭（先山）とは別種の労働で、含水層を突っ切るところが最大の難所。
常磐は出水量が桁外れなのでとくに危険だった。同書は『常磐炭田史』の主要文献目録に
収録されている当事者の手記。

- 面の開始演出: `STAGE n START` を**人車で立坑を降りる**演出に置き換える
- 音: 立坑を降りるときだけ BGM を止めて巻揚機の音だけにする。常磐炭坑節が戻ってくる
  瞬間が効く

#### 坑の呼び名 ── 地名＋番号＋坑種（2026-09-20 調査）

**作者の指摘「好間第一竪坑のように、地名＋第n＋竪坑で呼ばれていた」を裏付けた。**
幕（面の区切り）の名前を決めるときの資料。

### 5.6 エンディング

閉山後、炭鉱時代には煩わしかった地熱を逆手に取って常磐ハワイアンセンター
（現・スパリゾートハワイアンズ）が作られた。三井藤原炭礦の跡地に立ち、採炭時に
湧出して経営を圧迫していた排温水を温泉として利活用した施設で、常磐炭礦の理念
「一山一家」を体現しつつ「炭鉱から観光へ」の構造転換を象徴している。

**「40度の坑内で人が苦しんだ湯が、最後に人を楽しませる湯になった」**という筋は、
現在「文字数行だけ」のエンディングの中身として使える。

なお現行のエンディング本文は `TANNO SANJI HAS DUG OUT / ALL THE BLACK DIAMONDS.`
であり、**§8 の人物像が示す「帰る」ではなく「掘り尽くす」で書かれている**。
文面の変更は数十バイトで済み、第3部で最もすぐ手が届く箇所。

### 人物像（ゲーム機構としては一切実装しない）

1画面固定の坑内ゲームなので描写する場面がない。演出・トーン・細部の判断材料として
のみ記録する。

丹野三司氏は無類の酒好きだった。しかし結婚の際、祖母から**「外を飲み歩かないこと」**
を条件として提案され、了承した。その代わり祖母は**毎日の手料理と、刺身などの豪華な
食事**を約束した。**双方が、生涯にわたってこの約束を守り続けた。**

§6 の通り当時の炭鉱町は3交代で24時間動き、仕事終わりの店がにぎわい、給与も高かった。
飲み歩く条件は揃っていた。**その街にいながら、まっすぐ家に帰る側の人だった。**

- **「帰る」人である。** エンディングや面間演出で動詞を選ぶ場面があるなら、
  「掘り尽くす」「勝つ」ではなく「帰る」が合う（§5.6）
- **約束を守り続ける持続性。** 15面を黙々と掘り進む反復構造と性格が矛盾しない。
  派手さや一発逆転ではなく、同じことを何度でも正確にやる強さ
- 「一切喋らせない」案と整合する。**寡黙さは諦めや無愛想ではなく、自分で決めた
  ことを守り通す種類の静けさ**として描ける
- 好きなものを我慢していた人ではなく、**交換条件を了解して選び取った人**である。
  ここは重要で、**悲壮に描かないための歯止め**になる

明示的に画面に出す必要はない。挙動や間の取り方に迷ったときの照合先。

### じん肺の扱い（作者の決定事項）

**じん肺はゲーム要素として含めない。** ゲームオーバー条件、ペナルティ、能力低下など
のいかなる機構にも組み込まない。体温オーバーヒートは坑内で実際に起きたことなので
機構として妥当だが、じん肺は坑を出た後に来るものであり、遊びの失敗条件にすることは
題材の性質に合わない。

一方で、**炭鉱とじん肺が不可分であり、実際に訴訟と賠償が行われたという事実は
無視しない**（§4b）。置き場所の候補は README／同梱ドキュメントの「題材について」、
タイトル画面のコンフィグ配下の資料・クレジット画面、エンディング後の静止画面に
短い一文。いずれも**プレイヤーの操作を妨げない場所**に置き、ゲーム中には表示しない。
