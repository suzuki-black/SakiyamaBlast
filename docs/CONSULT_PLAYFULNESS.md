# 相談書: 遊び心と人間くささ — クロダイヤ 〜先山丹野3時〜

**別の人／AI に相談するための資料。** ゲームの現状ルールを全部ここに書き、そのうえで
「ボーナスや敵の表情など、**遊び心・人間くささ**を足して面白くできないか」を聞く。
数値はすべて 2026-09-20 時点のコードの実値。

## 0. 相談したいこと

作者が面1〜3を遊んだ感想はこうだった。

> なんかレトロアーケードの市販ゲーム凌駕してます。
> 多分もうちょっと遊び心加えると自分的に神ゲーに化ける気がします。

**ゲームの骨格（掘る・岩を運ぶ・連鎖で一気に採る）は完成している。** 次に足したいのは
ルールではなく、**遊んでいて思わず笑う・愛着がわく・覚えている瞬間**。観点は次の通り。

| 観点 | いまの状態（詳しくは §4） |
|---|---|
| **A. ボーナス** | 岩を2個割ると敵の巣に出る3種類だけ。黒ダイヤと無関係で、寄り道の理由が弱い |
| **B. 敵の表情・人間くささ** | 16×16 の1枚絵。**向きも歩きのコマも無い**。4種とも同じ形で色だけ違う |
| **C. 自機の人間くささ** | 17枚ある（歩き・構え・振り下ろし）が、表情や仕草は無い |
| **D. 間（ま）の演出** | 面の開始・クリア・ミス・ゲームオーバー・エンディングがほぼ文字だけ |
| **E. 題材（常磐炭鉱）の生かし方** | 水風呂と梅干しは史実から入れた。まだ使っていない素材がある（§6） |

### 答えてほしい形

案ごとに次を書いてほしい。**§5 の技術的制約と §7 の作者の方針を外した案は入らない。**

1. **何が起きるか**（画面と音で。プレイヤーから見た描写）
2. **なぜ面白いか／愛着がわくか**
3. **どのルールを「説明」しているか**（下の教訓を参照）
4. **コスト**：スプライト面・パターン枚数・背景タイル・VRAM 書き込み量・ROM／RAM の見積り
5. **リスク**：遊びの邪魔にならないか、読めない死因を作らないか
6. 全体の**優先順位**（効果とコストの比で）

### 過去の教訓（重要）

演出（ジュース）を10項目積んでも作者の体感は変わらなかった。効いたのは3つだけで、
どれも**ルールを絵で説明していた**。

- 岩が黒ダイヤを突き抜けて採る
- 連鎖が時間で繋がる（岩が採ったぶんも自分が採ったぶんも同じ連鎖）
- **かけらが自機へ集まる** ——「岩で鉱脈を割ると自分のものになる」を言葉でなく絵で伝えている

**見た目の派手さではなく、仕掛けの説明になっている演出だけが効く。**
遊び心・人間くささの案も、この基準で見てほしい。
（例: 敵の表情なら「その敵がいま何を狙っているか」「あと何秒で復活するか」が顔で読める、など）

## 1. ゲームの概要

- **MSX2 以降（MSX turbo R 推奨）**の1画面固定アクション。SDCC で C → ASCII8 MegaROM（128KB）
- 炭鉱夫「**丹野3時**」（作者の祖父がモデル。名前はもじった架空名）を操作し、
  地層を掘って**黒ダイヤ（石炭）を全部採掘したらステージクリア**。全15面
- 敵をよけ、上がり続ける**体温**を水風呂で冷ましながら掘る
- 骨格は Dig Dug ＋ Mr. Do!（メカニクスのみ参考。絵・音・曲はオリジナル）だが、
  **核は「岩を落として炭層を貫かせ、その連鎖が切れないうちに自分も採りに走る」**で、
  これに酷似したルールのレトロアーケードは見つかっていない

### 画面

| 項目 | 値 |
|---|---|
| 画面 | SCREEN 5（256×212、16色／512色中） |
| 盤面 | 16列×11行（1升16×16px）＝ 256×176 |
| HUD | 下36px。スコア6桁／面番号／体温メーター16目盛り／残機／ダイナマイト所持数／残り黒ダイヤ数／連鎖数 |
| フレームレート | 60fps 目標（掘っている間 55〜57） |

面の開始時、**面番号の形（算用数字）に掘り抜かれた坑道**がある。

### 操作

| 入力 | 動作 |
|---|---|
| カーソル／ジョイスティック | 4方向移動 |
| スペース／トリガA | **つるはし**（押しっぱなしで溜め） |
| B キー／トリガB | **ダイナマイトを投げる** |

## 2. 詳細ルール

### 2.1 自機

- 坑道内 60px/s、**未掘の土を掘り進む間は 40px/s**。方向転換は升の節点で
- 掘り跡は升の内側12×12px だけを抜く。**隣の坑道との間に 2px の「土の膜」が残り、
  これは敵が通れない本物の壁**（§2.8）
- **ミス条件は3つ**: 敵に触れる／**体温のオーバーヒート**／落ちてきた岩に潰される。
  ミス後1.5秒無敵

### 2.2 体温・水風呂・梅干し

- 体温は15フレームごとに+1、上限240＝**何もしなくても60秒でオーバーヒート**
- **つるはしを1回振るごとに +4**（溜めの威力に比例。空振りでも上がる）
- **水風呂**が盤面に1つ。重なっている間だけ少しずつ冷える。**何度でも入れる**
  （史実: 坑内は40度・湿度100%で、15〜30分働くごとに水風呂に入った）。
  冷えている間は湯の中を泡が上がる。**落ちてきた岩で壊れ、その面では戻らない**
- **梅干し**: 岩で潰した敵が必ず落とす。拾うと体温 -60（史実: 水風呂の後に梅干しで塩分補給）
- 体温が上がるほど **BGM が速くなる**（3段、最大1.38倍）。危険域では**盤面に陽炎**が立つ
  （横帯ごとに ±2px の揺れ）

### 2.3 黒ダイヤ（クリア条件）と連鎖

- 黒ダイヤは**掘れない障害物**。耐久度があり（面1で2〜面15で8）、つるはしで1ずつ削る。
  残りは升の右上に数字で出る
- 耐久0で**割れた絵**になり通れる。**割れた升に入ると採掘**
- 1本あたり最大4個の**繋がった炭層**として置かれる
- **連鎖**: 割れた黒ダイヤの升に入ると、繋がっている割れた黒ダイヤを全部同時に採る。
  さらに**3秒以内に採ったものは全部1つの連鎖**。岩が採ったぶんも自分が採ったぶんも同じ。
  得点は採った順に 200→400→800→…（1個3200で頭打ち）、一度に16個まで
- **割ったまま放置すると、敵が踏み抜けた升は耐久1で塞がり直す**。仕込んだ連鎖は
  敵の通り道にもなるので、欲張るほど崩されやすい
- **炭柱**: 耐久の高い特別な黒ダイヤ（面に2本、左右に分けて置く）。
  **壊すと、黒ダイヤの上に載っている岩が全部同時に落ちる（落盤）**。
  全画面の閃光・専用音・全敵が1段よろける

### 2.4 つるはし（溜め打ち）

- 押した瞬間に威力1で1振り。**押したまま0.5秒ごとに1段、最大3段まで溜まる**。離すと一撃
- 振り切るまで0.3秒動けない（ここに敵が寄ってくる）。使用回数は無制限
- 敵に当てると**よろけ**させる（§2.7）

### 2.5 ダイナマイト

- 弾薬制。面の開始時は0本、**火薬（面に10個）を拾うと+1**、次の面へ持ち越す
- 向いている方向へ最大5升飛ぶ。途中に敵が居ればそこで爆発（爆風は1升だけ・地形は掘らない）
- 何にも当たらなければ落ちてアイテムになる（拾い直せる）

### 2.6 岩（規則は6つだけ）

```
1. 真下が塞がっていれば止まる（支えは岩の中心で見る）
2. 左右に押せる（上下には押せない）。自機は土の中へも押し込める
3. 落ちる先が黒ダイヤなら、貫いて採る（割れていなくても）
4. 落ちる先が樋（とい）なら、板を壊して、傾いている方向へ1升ずれてから落ち続ける
5. 2升以上落ちるか、何かを潰したら割れる
6. 落ちてきた岩が岩に着地したら、落ちてきたほうが割れる（押して乗せただけなら割れない＝積める）
```

- **割れていない黒ダイヤは岩の支えになる。割ると坑道になって岩が落ちる。**
  「割る＝通す、割らない＝支える」が連鎖の組み立てそのもの
- 岩は常に 2px/フレームで動く（下へか、樋では横へ）。**勝敗は経路の升数だけで決まる**
- 真下に自機が居る間は落ちてこない（Dig Dug 準拠。好きなだけ待てる）
- 支えを失うと0.75秒揺れてから落ちる。押している岩が升の境目を越えた瞬間に「カチッ」と鳴る
- **1行に岩は1個まで**（スプライトの横一列8枚制限のため）
- **樋（とい）**: 坑内で石炭を下へ流す斜めの板。岩が横へ動く唯一の手段。
  板の傾きがそのまま行き先を示す（右下がりなら右へ）。使うと「折れた板」の絵が残る

### 2.7 敵

**4種とも同じ形で色だけが違い、色ごとに狙う升の決め方が違う**（パックマンのゴースト準拠）。
面に出る敵は3〜6体で、赤→桃→水→橙の順に色を配る（5体目からは赤・桃がもう1体ずつ）。

| 色 | 役 | 狙う升 | 速さ |
|---|---|---|---|
| 赤 | 追いかけ | 自機の升 | 35px/s |
| 桃 | 待ち伏せ | 自機の向きの4升先 | 30px/s |
| 水 | 気まぐれ | 赤の位置から見て、自機の2升先を倍に伸ばした升（敵同士の連携） | 30px/s |
| 橙 | お惚け | 6升より遠ければ追い、近いと自分の隅へ引く | 25px/s |

- 全員が「散開」5秒⇄「追跡」20秒を切り替える
- **敵は自分で掘らない。** 自機が掘った坑道しか歩けず、土の膜も通れない
- **透明化**: 一定時間で透明になり、土を斜めにすり抜けて迫る（7.5px/s と遅い）。
  **自機が掘るほど透明化が早まる**（切羽圧: 1升掘るごとに0.05秒縮む。面1で10秒→下限5秒）。
  透明になる1秒前から速く点滅して予兆を出す
- **よろけ**: つるはしで叩くと**潰れて動かなくなり、触れても安全**。3段まで深くなり、
  2秒ごとに1段戻る（絵が縦11行→9→7→4行と潰れていく。ディグダグの「膨らむ」の逆）
- **プール制**: 面1で3体〜面10以降6体。倒されても消えず、**巣（湧き出し口）で静養してから
  同じ個体が戻ってくる**（面1で10秒〜面15で4秒）
- 湧いた直後は2秒間その場で点滅（動かず当たらない）

**色は「その敵のアルゴリズム」を表す情報なので、状態表示に色を使ってはいけない**
（よろけても色は変えない）。

### 2.8 土の膜

掘り跡の間に残る 2px の膜は**本物の壁**で、升の境目ごとに「抜けているか」を持つ。
自機が境目を跨いで掘る・黒ダイヤが割れる・岩が縦に突き破る、で抜ける。
敵は膜を歩いて抜けられない（透明化するしかない）。**これが敵の圧を大きく下げている。**

### 2.9 ボーナス

**岩を2個割ると、敵の巣の升に10秒だけ出る。** 上を通ると取得。

| 種類 | 効果 | 出現率 |
|---|---|---|
| 得点 | 1000点 | 5/10 |
| 体温回復 | 体温を0に | 3/10 |
| 残機+1 | | 2/10 |

### 2.10 得点

| 行為 | 点 |
|---|---|
| 土を1升掘る | 5 |
| 火薬を拾う | 10 |
| 黒ダイヤを割る | 50 |
| **黒ダイヤを採掘** | **200→400→800→…（連鎖。1個3200で頭打ち）** |
| ボーナス | 1000 |
| 面クリア時 | 採掘率1%あたり20／残ダイナマイト1本あたり100 |
| 敵を倒す（爆風） | 同時1〜5体で 100/200/400/600/800 |
| **敵を倒す（落ちる岩）** | **同時1〜5体で 200/400/800/1200/1600**（Mr. Do! のリンゴと同じ比） |

倒した升・採った升に点数を1秒出す（800点以上は倍角）。

### 2.11 ステージ構成（全15面）

**盤面は面番号だけで決まる**（毎回同じ）。候補を6万通り総当たりし、条件を満たすものを選んでいる。

- **面1**は教材。岩は最初から炭層の真上にあり、1手で5個採れる
- **面2から、岩の一部を炭層の真上から横へずらして置く。**押して揃えないと炭層を貫かない。
  ずらす数は 面2〜3で1個、面4〜9で2個、面10〜15で3個
- **樋は面4（第二坑）から出る。**第一坑（面1〜3）は「岩は真下にしか落ちない」で完結する
- **準備すればするほど一気に採れる**ように選んである

| 面 | 1 | 4 | 7 | 10 | 15 |
|---|---|---|---|---|---|
| 盤面の黒ダイヤ | 6 | 7 | 8 | 9 | 12 |
| 押さずにつるはし1本で採れる数 | 5 | 3 | 3 | 2 | 2 |
| 岩を1個揃えてから | ― | 5 | 5 | 6 | 8 |
| **ずらした岩を全部揃えてから炭柱を割る** | ― | **7** | **8** | **9** | **11** |

- 炭層・炭柱・岩は**左右に散らして**置く
- 敵の数・静養時間・透明化までの時間・黒ダイヤの耐久は面が進むほど厳しくなる
- 15面クリアでエンディング → 裏面（**裏面の中身は未実装**）

## 4. 観点ごとの現状（詳しく）

### A. ボーナス

- 出現条件は**岩を2個割る**だけ。出る場所は**敵の巣**（取りに行くのに危険が伴う）
- 3種類（得点／体温0／残機+1）。**黒ダイヤや連鎖と関係が無い**ので寄り道の理由が弱い
- 絵は背景タイル3枚（`BSCORE` `BCOOL` `BLIFE`）。梅干しは体温回復の絵を流用
- 保留中の案: 爆風の威力アップ／ダイナマイト同時設置数アップ（爆風と未掘部分の強弱の見極めが要る）

### B. 敵

- **パターンは4枚だけ**: 通常1枚（4方向とも同じ・歩きのコマ無し）＋よろけ3段
- 4種は同じ形で色だけ違う。**色＝アルゴリズムの情報なので、状態を色で表してはいけない**
- 透明化中は色を抜く（形は同じ）。予兆は点滅
- **使っていないコウモリの絵が1枚ある**（昔の名残）
- 性格（追いかけ・待ち伏せ・気まぐれ・お惚け）は**動きにはあるが、見た目には無い**

### C. 自機

- 17枚: 正面1（面の開始時だけ）／歩き4方向×2／溜めの構え4方向／振り下ろし4方向
- **つるはしと汗は背景に描いている**（スプライトが1行1色で持たせる余地が無いため）
- 作者の方針として**一切喋らせない**案がある（§7）

### D. 間の演出

§2.12 の通り、ほぼ文字とジングルだけ。エンディングも文字数行。

### E. 題材

§6 の史実素材のうち、ゲームに入っているのは**水風呂・梅干し・炭柱（残柱式）・樋・
黒いダイヤ（タイトル）・常磐炭坑節**。

## 5. 技術的な制約（ここを外した案は入らない）

### 速度: 律速は VDP（画面への書き込み）であって CPU ではない

| 状態 | fps（Z80 3.58MHz） | fps（turbo R 実機） |
|---|---|---|
| 止まっている | 60 | 60 |
| 掘っている | 55 | 57 |
| 陽炎が出ている | 44 | 56 |

- **turbo R では起動時に R800 DRAM モードへ切り替えている。**速くなるのは内蔵 DRAM に
  あるもの（BIOS・割り込み処理・RAM へ写したコード）だけで、**VDP への書き込みは速くならない**
- 面の開始で画面を消している時間は 2.5〜3.5秒（盤面の組み立て）

### タダに近いもの／高いもの

| ほぼ無料 | 高い |
|---|---|
| **パレット操作**（数バイトで画面全体の色が変わる） | 背景への描き足し（VRAM 書き込み） |
| **画面揺れ**（R#18。縦横とも） | 広い塗りつぶし |
| **ヒットストップ**（数フレーム止めるだけ） | 大きな絵 |
| **PSG**（音量・音程・ノイズ） | スプライトの絵の差し替え（VRAM 転送） |
| スプライトの座標移動 | |

**いちばん費用対効果が高いのはパレット。**

### スプライト（mode 2、16×16）

- 32面のうち **22面使用**（自機1・爆弾1・岩8・敵6・かけら6）。**10面空き**
- **横一列に8枚まで**（9枚目以降は消える）
- **1行1色**（行ごとに色は変えられるが、1行の中では1色）。重ねて色を増やすと面と横一列の枠を食う
- パターンは26枚使用（うち1枚未使用のコウモリ）

### 色

512色中16色。パレットは面ごと・場面ごとに差し替えられる。**敵の4色は情報なので流用しない。**

### ROM／RAM の空き

| 置き場 | 空き | 置けるもの |
|---|---|---|
| 固定領域 0x4000-0x9FFF | **1958 バイト** | 何でも |
| バンク窓 0xA000-0xBFFF | 443 バイト | 絵・曲のデータ、コード |
| RAM 実行 0xD000-0xEDFF | **175 バイト** | 起動時に写して RAM で動かすコード |

（2026-09-20 に `sound` を RAM 実行へ移して固定領域を空けた。次に空けるときは RAM 実行の
領域を下へ広げるか、バンクのセグメントを増やす）
| **ROM 全体（MegaROM）** | **容量は制約ではない** | 絵・曲・面データはバンクへいくらでも足せる（128KB → 256KB も可） |

**コードを足すときは、既存モジュールを RAM 実行へ移して固定領域を空ける**必要がある（手順は確立済み）。
データ（絵・文字・曲）は ROM を増やせば入るので、**大きな絵や多くのパターンは問題にならない**。
制約は「同時に画面へ出せる量」と「VRAM へ書き込む時間」のほう。

### 音

- PSG 3声、矩形波固定。BGM は3声とも使っている
- 効果音は ch C（ドラム）を一時的に奪って鳴らす（優先度つき、12種）

## 8. 既に検討済みの案（再提案は不要）

### 実装側で温めている案（未実装）

1. 連鎖の**残り時間**を見せる（減る帯／点滅）
2. 連鎖が深まるほど**土の色が赤熱**する（パレットのみ）
3. 連鎖の瞬間だけ **BGM の音量を下げて**採掘音を前に出す
4. 連鎖が終わった瞬間に**最終連鎖数に応じた短いアルペジオ**
5. **かけらを連鎖で増やす**

### 入れたが効かなかったもの（同じ方向の案は効かない見込み）

採掘の音と閃き、得点ポップアップ、岩の破砕演出、岩の増量、まとめ撃破の計上、
梅干し、切羽圧、溜め打ち、よろけ、自機のアニメーション —— どれも入れて残してあるが、
**これらを積んでも「爽快感が足りない」は解決しなかった。**解決したのは §0 の3つ。

### 却下した案

| 案 | 理由 |
|---|---|
| ダイナマイトで地形を埋める | 「投げる武器・地形を掘らない」の逆転。籠城の抜け穴 |
| 周囲を掘ると岩が不安定になる | 読めない死因を作る |
| 黒ダイヤを割ると周囲が掘りにくくなる | 推奨したい行動を罰する |
| 火薬が時間で劣化 | 次の面へ持ち越す仕様を無効化する |
| 水風呂を1面1回に制限 | 史実に反する（反復入浴が実態） |
| 岩が掘っていない土の中を落ちていく | **違和感しかない**（作者の体感）。岩は土を突き抜けない |
| 岩の横滑り・沈み込み・着地の衝撃波・倒れ込み | 読めない。岩の横移動は樋だけにした |
