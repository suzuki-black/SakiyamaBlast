# 岩の規則の再設計 ── 樋（とい）の導入と横滑りの廃止

`ROCK_SLIDE.md` §6 の相談を経て到達した結論。
**「わかりやすさ＝単純さ」**を基準に、岩に付いた規則を減らし、
横方向の伝播を新ギミック1つに集約する。

- 対象: `src/rock.c` / `src/field.c` / `src/game.h`
- 予算: 固定領域 0x4000-0x9FFF に **2150 バイト**
- **正味の増減: マイナス（コードが減る見込み）**

---

## 0. 診断 ── 岩1つに規則が8つ付いていた

「複雑」と感じた原因は、ギミックの数ではなく**1つの物に付いた規則の数**にある。

いま岩を理解するには、これを全部覚える必要がある。

1. 支え（中心判定）
2. 押し
3. 落下
4. 2升以上で割れる
5. 黒ダイヤを貫く
6. **落盤では沈み込みぶん沈んで素通り**
7. **岩に乗ると上が割れて下が滑る**
8. **滑る向きは左右の坑道の数で決まる**

**6・7・8 はどれも「岩」という同じ絵で起きるので区別がつかない。**

### 沈み込みが元凶

とくに **6（沈み込み）** が悪さをしていた。

- ゲーム内に他に類例が無い
- 数字は別の物（炭柱）の升に書いてある
- 岩がどこまで沈むか目に見えない
- 「行差 ＝ 沈み込み ＋ 1」という**不可視の条件**を生み、横滑りをほぼ不可能にしていた
  （`ROCK_SLIDE.md` §2.2 の実測: 15面で発動1回）

**これまでの行き詰まりの大半はここが原因。**

## 1. 残すもの・消すもの・加えるもの（一覧）

### 1.1 岩の規則

| # | 規則 | 判定 |
|---|---|---|
| 1 | 真下が塞がっていれば止まる（**支えは岩の中心で見る**） | **残す** |
| 2 | 左右に押せる（自機・敵とも。1ドットずつ、自機と同じ速さ） | **残す** |
| 3 | **落ちる先が黒ダイヤなら、割れていようがいまいが貫いて採る** | **残す（連鎖の心臓。絶対に触らない）** |
| 4 | 2升以上落ちるか、何かを潰したら割れる | **残す** |
| 5 | **落ちてきた岩が岩に着地したら、落ちてきたほうが割れる**（押して乗せた場合は割れない） | **残す** |
| 6 | 落盤では沈み込みブロック数だけ沈み、その間は下に何があっても素通りする | **廃止** |
| 7 | 岩が岩に乗ったとき、下の岩が横へ1升滑る | **廃止** |
| 8 | 滑る向きは「左右のうち坑道がちょうど一方だけ」で決める | **廃止** |
| 9 | **落ちる先が樋なら、板を壊して傾いている方向へ1升ずれ、落下を続ける** | **新規** |

**8つ → 6つ**（うち1つが新規なので、実質 8 → 5 + 1）。

### 1.2 検討したが採らなかった案（すべて取り下げ）

| 案 | 取り下げの理由 |
|---|---|
| **着地衝撃波**（左右3升へ三角形の減衰） | 三角形の減衰は**盤面上で暗算しないと結果が読めない**。単純さの基準に反する |
| **倒れ込み**（真横の黒ダイヤが割れたら岩がその穴へ倒れる） | 衝撃波とセットの機構だったので同時に取り下げ |
| **未割の黒ダイヤでは止まる**（貫通の制限） | **連鎖の心臓を抜いてしまう。** これを入れると「割った数＝連鎖の長さ」で確定し、落ちてから何かが起きる余地が消える。単なる回収になる |
| **岩×岩の滑りの向きを変える案**（自機側／遠い側など） | 樋が横移動を全部引き受けるので、岩×岩に仕事が残らない |
| **沈み込み中も岩との接触を見る**（`ROCK_SLIDE.md` §5-B） | 沈み込み自体を廃止するので不要 |

### 1.3 炭柱

| | 変更 |
|---|---|
| 一番硬い黒ダイヤであること | **残す** |
| クリア条件に含まれること | **残す** |
| 割ると落盤が起きること | **残す** |
| **沈み込みブロック数（升の左下の数字）** | **廃止。落盤は「盤面の全部の岩が支えを失って落ちる」だけ** |

## 2. 新ギミック ── 樋（とい）

### 2.0 何のことか

炭鉱の**シュート（chute）**、日本語で**樋（とい）**は、坑内で石炭を上の坑道から
下へ落とすための**斜めに架けた木の樋**。滑り台と同じ理屈で、掘った石炭を人力で
運ばずに重力で下ろす。坑木や板を斜めに組んで作られていた。

常磐炭田は炭層が海側へ7〜10度傾斜していたので、この手の落とし込みは日常的だったはず。

```
     ＼            ／
      ＼          ／
   左下がりの樋   右下がりの樋
   → 岩は左へ    → 岩は右へ
```

**升1つに斜めの板が1枚描いてあるだけ**の背景タイル。
本文中では **「樋」** で統一する。

### 2.1 何か

盤面に固定して置かれる、**斜めの板**。右下がりと左下がりの2種類。

> **岩が樋の升に落ちてくると、板を壊し、傾いている方向へ1升ずれて、落下を続ける。**

数字も、左右の比較も、強さも、減衰も無い。

### 2.2 なぜこれで良いか

**絵そのものが規則になる。** 斜めの板が右を向いていれば岩は右へ行く。
プレイヤーは**落とす前に、盤面を見るだけで岩の通り道を最後まで指でなぞれる。**
ぷよぷよで連鎖を組む前に目で追えるのと同じ状態。

**炭鉱の道具として正しい。** 坑内では実際に石炭を斜めの樋で滑らせて落としていた。

**制約に一切触らない。** 背景タイル1枚なので、
**スプライトを使わず、「1行1個」にも横8枚制限にも関係しない。**

### 2.3 細部（4点）

| # | 仕様 | 理由 |
|---|---|---|
| ① | **板は土の升の中に、最初から見えている。掘り出すまで岩は通れない** | **「岩から板まで穴を掘る」が仕込みの作業**になる。掘るという既存の動詞だけで完結する |
| ② | **行き先が塞がっていても、板は壊れる。** その場合、岩は曲がらずそのまま真下へ落ち続ける | 「板は必ず壊れる。曲がれれば曲がる」の1文で済む |
| ③ | **板はつるはしでは壊せない。** 壊すのは岩だけ | 規則を増やさない |
| ④ | **壊れた升は普通の坑道になる** | 特別な状態を残さない |
| ⑤ | **押している岩が樋の升に入っても、何も起きない。** 板の上を素通りして通り過ぎる（**決定**） | 板を壊すのは落下の衝撃、という一貫性を保つ。「押して樋を渡らせる」はできなくなるが、規則が増えないほうを取る |
| ⑥ | **曲がった先が土なら、曲がらずそのまま真下へ落ちる。** 土は掘れるので、掘っておけば曲がるようになる（**決定**） | 「掘って経路を作る」がそのまま仕込みになる |
| ⑦ | **曲がった先に敵がいたら潰す**（**決定**） | 落下中なので既存の撃破処理がそのまま使える |
| ⑧ | **曲がった1升は落下距離に数えない**（**決定**） | 数えると、樋を通った岩がすぐ砕けて連鎖が続かなくなる |
| ⑨ | **曲がった先に岩がいたら、落ちてきたほう（曲がってきたほう）が割れる**（**決定**） | 規則5がそのまま適用される。例外を作らない |

### 2.4 なぜ「壊れる」ほうが良いか

**消耗品になるので順番が意味を持つ。** 面に2〜4枚しかない使い切りの資源なら、
「どの岩をどの板に通すか」が計画になる。地形として永続だと同じ板を何度も使えて、
考える必要が減る。

**壊れる瞬間が合図になる。** 曲がったことを板の破片と音で伝えられる。
永続だと「通り過ぎた」だけで見落とす。

**史実として正しい。** 坑内の樋は木製で、岩が落ちれば壊れる。

### 2.5 枚数

- **低次面 2枚**（経路が1本）
- **高次面 4枚**（分岐が生まれる）

## 3. 岩と岩がぶつかったとき

### 3.1 結論：何もしない

> **上の岩が割れて消える。下の岩は動かない。**

現行から滑りを削除するだけ。**コードは減る。**

**理由**: 樋が横移動を全部引き受けたので、岩×岩に仕事が残っていない。
15面に1回しか起きない事象に規則を割り当てると、
**「出会えないのに覚えなければいけないもの」がまた増える。**

### 3.2 「1列1個」は成立しない（検討して却下）

一度「配置に1列1個を足す」を検討したが、**岩は横に押せるので実行中は守れない。**

- **「1行1個」は実行中も守られる。** 岩は自力で行を移動しない
  （樋で横1升ずれても行は変わらない）
- **「1列1個」は初期配置でしか守れない。** 押しと落下で簡単に破れる

そして規則5があるので、**そもそも制約として要らない。**
同じ列に2つ来ても、落ちてきたほうが割れるだけで何も困らない。

### 3.3 「ぶつかったら壊れる、置いただけなら壊れない」

規則5の書き方には注意が要る。

```
落ちてきた岩が岩に着地したら、落ちてきたほうが割れる
押して岩の上に乗せた場合は割れない
```

**「岩の上には止まれない」ではない。**
押して岩の真上まで運んだだけで突然割れたら、プレイヤーは理由が分からない。

**ぶつかったら壊れる、置いただけなら壊れない。** これは説明が要らない区別で、
誰でも物理的に知っていること。

`ROCK_SLIDE.md` §1.1 によれば、判定は `rock_fall_step` の中、
**落下中の岩が升の境目に達した瞬間**にだけ走っている。
押しは別の処理なので、**現状のコードは既にこの通りに動いている可能性が高い。**
要確認だが、直すのはドキュメントだけで済むかもしれない。

### 3.4 積めることには使い道がある

押して岩の上に岩を乗せられるなら、**プレイヤーが自分で2段の縦連鎖を仕込める。**

```
下の岩の支えを外す
  → 下が落ちて炭層を貫く
  → 支えを失った上の岩が、遅れて同じ穴へ落ちる
```

**時間差の連鎖を、樋なしで、押すだけで作れる。**
追加コードはゼロで、既存の規則の組み合わせから出てくる。
「積む」は目で見て分かるので複雑さも増えない。

積んだ岩は行が1つ違うだけなので、**「1行1個」にも触れない。**

## 4. 沈み込みを消すと落盤がどうなるか（要確認事項）

### 4.1 沈み込みは「1行1個」を守る仕組みでもあった

全部の岩が同じ量だけずれるので行が重複しない。
**これを消すと岩がばらばらの距離を落ちる。**

### 4.2 既存の規則が救ってくれる

**行の重複はそもそも起きない。** 岩は自力で行を移動しないため
（樋で横1升ずれても行は変わらない）、初期配置で「1行1個」を守れば維持される。

**列の重複は規則4と規則5が処理する。**
岩は2升以上落ちると割れる（規則4）ので、落盤では大半の岩が
**貫通で炭層を採ったあと、割れて消える。**
残った岩の上に別の岩が落ちてきたときは、規則5で落ちてきたほうが割れる。

### 4.3 結果として落盤はこうなる

> **盤面の全部の岩が一斉に落ちて、炭層を貫いて、砕け散る。**

**面の最後の大花火**になる。炭柱を「面のボス」として扱う設計と噛み合う。

そして**「岩を使い切ってから炭柱を割るか、全部まとめて炭柱に賭けるか」**
という順番の判断が生まれる。

### 4.4 確認したいこと

**落盤で面の岩がほぼ全滅することを許容するか。**

面の後半に「押せる岩を残して敵を潰す」設計を想定していたなら、方針転換になる。

## 5. 規則の全文（実装用）

```
岩
  1. 真下が塞がっていれば止まる（支えは岩の中心で見る）
  2. 左右に押せる
  3. 落ちる先が黒ダイヤなら、貫いて採る
  4. 落ちる先が樋なら、板を壊して、傾いている方向へ1升ずれてから落ち続ける
     （ずれた先が塞がっていれば、曲がらずそのまま落ちる）
  5. 2升以上落ちるか、何かを潰したら割れる
     （樋で横へずれた1升は、落下距離に数えない）
  6. 落ちてきた岩が岩に着地したら、落ちてきたほうが割れる
     押して岩の上に乗せた場合は割れない（積める）

樋
  最初から見えている。掘り出すまで岩は通れない。つるはしでは壊せない
  右下がりの板は右へ、左下がりの板は左へ
  落ちてきた岩が通ると必ず壊れ、普通の坑道になる
  曲がった先が塞がっていれば、曲がらずそのまま落ちる
  押している岩が通っても、板は壊れないし曲がらない

炭柱
  一番硬い黒ダイヤ。割ると盤面の全部の岩が支えを失って落ちる
```

**消えるもの**: 沈み込み、素通り、左右の坑道の比較、行差の一致、
衝撃波、減衰、倒れ込み、横滑りの向き判定。

## 6. 連鎖はどう成立するか

### 6.1 貫通が心臓

「落ちる」と「割る」と「採る」が1つの動作に束ねられているから、
**次の結果が次の結果を生む。** ここを触ってはいけない。

### 6.2 樋が横へ広げる

```
行1        岩
行2       ◆ ◆ ◆        ← 縦の炭層A
行5       樋（右下がり）
行6              ◆ ◆ ◆   ← 縦の炭層B
行9              樋（左下がり）
行10      ◆ ◆            ← 炭層C
```

岩の下を掘る
→ 落ちて**炭層Aを3個貫く**（200 / 400 / 800）
→ 樋で右へ1升
→ **炭層Bを3個貫く**（1600 / 3200 / 3200）
→ 樋で左へ1升
→ **炭層Cを2個**

**1回の落下で8個。**
列を渡るたびに落下と横移動が入るので、**2〜3秒かけて盤面を斜めに降りていく。**
時間差の連鎖になる。

そして**落とす前に指でなぞれる。** 組めるし、読める。

### 6.3 つるはしで仕込む意味

貫通が残るので、**割ってあるかどうかは連鎖の長さに影響しない。**
では何のために割るのか。

炭層の途中を1個だけ割ると、そこが通れる升になり支えが消える。つまり、

- **割った升は、岩を通す穴になる**（列の途中で止めたくないとき）
- **割らずに残した升の上には、別の岩を置いて待たせられる**（既存の「黒ダイヤは岩の支えになる」）

> **割る＝通す。割らない＝支える。**

連鎖を組むとは、**どの升を通し、どの升で支えるかを決める作業**になる。
ぷよの「どこに置くか」に相当する。

さらに割った升は敵の通路になる（既存）ので、
**仕込むほど盤面が敵のものになる**という課税構造もそのまま生きる。

## 7. ステージ1 構成案

```
行1        岩
行2    (プレイヤーが掘る)
行3       樋（右下がり）
行4              ◆耐久2
行5              ◆耐久2
行6              ◆耐久2
行7              ◆耐久2
```

岩は炭層の**1列左**、その2升下に樋。

**プレイヤーは岩の下を2升掘るだけ。**

**掘る前から、指で経路をなぞれる。** 板の向きが見えていて、その先に炭層が見えている。

| **樋を使う** | 2升掘るだけ | **3000** | 掘る間に敵が来る。割れた炭層は敵の通路になる |

## 9. `pick_seeds.py` への影響

**貫通が残るので、現行の `free`（岩の真下にある黒ダイヤの数）は引き続き有効。**
衝撃波を採らなかったので、`side` のような新指標は不要。

加えるのは1つだけ。

```
reach = 樋を経由して、1回の落下で到達できる炭層の総数
        （実際にエンジンを走らせて測る）
```

**全面で `reach >= 4`** を合格条件にする。面1でも大連鎖の余地があること。

**配置の制約は「1行1個」のみ。** 「1列1個」は押せる以上守れないので入れない（§3.2）。

## 10. リスク

- **落盤で面の岩がほぼ全滅する。** §4.4 の通り、許容するか要判断
- **落盤は上の行の岩から1つずつ順に落とす**のが素直。
  同時に落とす必要は無く、上から下へ解けていく見せ場になる
- **樋の枚数が多いと、盤面が読みにくくなる。** 低次2枚から始める
- **樋を掘れるようにするかどうか。** 掘れないほうが単純で、盤面が固定の地形として
  読める。掘れると自由度は上がるが規則が1つ増える。**掘れないことを推奨**
- **板の絵をスプライトにするか背景タイルにするか。** **背景タイルなら8枚制限に一切触れない。**
  壊れる演出だけスプライトで木片を1〜2枚飛ばすのが安い
