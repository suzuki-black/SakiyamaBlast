# クロダイヤ 〜先山丹野3時〜 現状のゲームルール一覧

MSX turbo R 向け（SDCC / ASCII8 MegaROM）。1画面固定の掘り＋採掘アクション。
**別の人／AI に相談するための資料**なので、決まっていない点・未実装・不具合も
そのまま書いてある。数値はすべて 2026-08-29 時点のコードから拾った実値。

- 実装: `src/*.c`（調整用の定数はほぼ `src/game.h` に集約）
- 面ごとの表: `src/field.c` の `coal_n_tbl` / `coal_hp_tbl`

---

## 0. 一行で言うと

炭鉱夫「丹野3時」を操作し、**地層を掘って黒ダイヤ（石炭）に辿り着き、つるはしで
砕いて全部採掘する**。敵をよけ、体温の上昇を風呂で冷ましながら進む。

---

## 1. 画面と盤面

| 項目 | 値 |
|---|---|
| 画面 | MSX2 SCREEN 5（256×212、16色） |
| 盤面 | 16列 × 11行 = **176升**（1升16×16px、上176px） |
| HUD | 下36px。スコア6桁／面番号／体温メーター16目盛り／残機／ダイナマイト所持数／**残り黒ダイヤ数** |
| フレームレート | 60fps（敵4体でも維持。実測 59.8〜60.0） |

面の開始時、**面番号の形に掘り抜かれた坑道**が置かれる（1〜15 の算用数字）。
数字の形なので**ばらばらの島に分かれる**（面2は7つ、面12は9つ）。

---

## 2. 操作

| 入力 | 動作 |
|---|---|
| カーソルキー / ジョイスティック | 4方向移動（斜めなし） |
| **スペース / トリガA** | **つるはし**を振る |
| **B キー / トリガB** | **ダイナマイトを投げる** |
| 上上下下左右左右BA（タイトルで） | コンフィグ画面 |

## 3. 自機（丹野3時）

- **坑道内 60px/s、未掘の土を掘り進む間は 40px/s**（Dig Dug / Mr.Do! 準拠の減速）
- **方向転換は升の節点で**。半歩ずれていれば最寄りの節点へ寄せてから曲がる（Dig Dug 準拠）
- 掘り跡は**升の内側12×12px だけを抜く**。結果、隣り合う坑道の間に**薄い土の膜**が2px残る
- 向きは**キーを離しても保持**する（止まったままでも武器を使えるように）
- ミス条件は3つ:
  1. 敵に触れる
  2. **体温がオーバーヒート**する
  3. 落下してきた岩に潰される
- ミス後 90フレーム（1.5秒）無敵

### 体温と風呂

- 15フレームごとに体温+1、上限240 = **60秒でオーバーヒート**して1ミス
- 盤面に**風呂が1つ**。その升を通過すると体温が一気に0へ戻る。**何度でも入れる**
- 風呂は**落下してきた岩で壊れる**（壊れるとその面では復活しない）。
  ダイナマイトでは壊れない

---

## 4. 黒ダイヤ（石炭）＝ クリア条件

**盤面の黒ダイヤを全部採掘したらステージクリア。**

- 土と違い**掘り進めない障害物**。自機も敵も通れない
- **耐久度**を持ち、つるはしで1回叩くごとに1減る。残りは升の**右上に数字で表示**
- 耐久度0で**割れた絵に変わり、通れる升になる**。そこへ**入ると採掘**（残数が減る）
- 割れた瞬間: **破砕音＋画面を縦に揺らす**（R#18 = SET ADJUST を10フレーム）
- 配置は1個ずつではなく**繋がった炭層**（1本あたり最大4個）
  - 実測: 面1は4個が1本、面15は10個が4本（平均2.5個/本）

### つるはし

- **向いている先の升が黒ダイヤのときだけ**振れる
- 1回振り切るまで **18フレーム（0.3秒）動けない**。ここに敵が寄ってくるのが駆け引き
- **使用回数は無制限**（回数制限やアイテムでの回数増加は今後の検討事項）
- 効果音は 低いノイズのアタック → 約4kHz から落ちる金属音「キン」

---

## 5. ダイナマイト（投げる武器）

- **弾薬制。面の開始時のストックは0**。火薬を拾うと+1、**次の面へ持ち越す**
- B ボタンで**向いている方向へ投げる**。最大**5升**飛ぶ（1升4フレーム）
- 飛行中に**敵が居ればそこで爆発**。**爆風は1升だけ**で、
  **地形は掘らない／土の膜も壊さない／風呂も壊さない／岩も壊さない**
- 敵以外の障害物（未掘の土・黒ダイヤ・岩・風呂）があれば**その手前に落ちる**
- 何にも当たらなければ**5升先に落ちる**
- 落ちたダイナマイトは**アイテム**。拾い直せる。障害物にならず、敵は素通りする
- **投げる先が塞がっていると投げない**（消費もしない）。低い「コツン」が鳴る。
  ただし**隣に敵が居るときは塞がっていても投げられる**（ゼロ距離）
- 同時に飛ばせるのは1個

### 火薬

- 面ごとに**10個**（面によらず一定）。土の中に配置。拾うとストック+1

---

## 6. 岩

- 面ごとに2〜4個。土の中に配置（真下が土の升にのみ置く）
- **真下の升に自機が居る間は落ちない**（Dig Dug 準拠。好きなだけ待てる）
- 支えが外れると 45フレーム揺れてから落下（2px/frame）
- **横に押せる**。押した先に敵が居れば**押し潰せる**（落とさなくても武器になる）
- 落下中は**縦一列の敵をまとめて潰す**（同時に倒すほど得点が伸びる。落下岩は爆風の倍）
- 自身の高さを超えて（2升以上）落ちるか、何かを潰したら**割れて消える**
- **落ちてきた岩は風呂を壊す**
- **岩を2個割ると盤面中央にボーナスが出る**（10秒で消える）

---

## 7. 敵

姿は4種とも同じで**色だけが違う**。**色ごとに狙う升の決め方が違う**（パックマンのゴースト準拠）。

| 色 | 役 | 狙う升 | 速さ |
|---|---|---|---|
| 赤 | 追いかけ | 自機の升そのもの | 35px/s |
| 桃 | 待ち伏せ | 自機が向いている方向の**4升先** | 30px/s |
| 水 | 気まぐれ | 自機の2升先を、**赤の位置から見て倍に伸ばした升**（＝敵同士の連携） | 30px/s |
| 橙 | お惚け | 自機まで6升より遠ければ追い、**近いと自分の隅へ引く** | 25px/s |

- 全員が**「散開」5秒 ⇄「追跡」20秒**を切り替える。散開中は各自バラバラの隅を狙う
- 交差点では**引き返し以外で狙う升にいちばん近づく方向**を選ぶ（同点は 上→左→下→右）。
  ただし 1/16 の確率だけランダムに揺らす（盤面が毎回違うのでパターンを覚えられないため）
- **敵は自分で掘らない**（Dig Dug 準拠）。自機が掘った坑道しか歩けない
- **土の膜が残っている境目は歩いて抜けられない**。抜けたければ透明化するしかない
- 一定時間（面1で10秒、高次面で5秒）経つと**透明化して土を斜めにすり抜ける**。
  この間の速さは **7.5px/s**（素の1/5程度）。坑道に出ると実体化する
- 透明中も**触れると死ぬ**

### 湧き出し口

- 面番号の掘り抜きとは別に、**坑道に面した升に1ブロックの横穴**を開ける
  （孤立させると湧いた瞬間に透明化して盤面のどこからともなく現れてしまう）
- 出発点から6升以上離す
- 湧いた敵は**2秒間その場で点滅**する。**その間は動かず、触れても当たらない**
- 総数は面ごとに `4+面`（上限19）。同時に画面に出るのは最大4体
- 次が湧くのは、一定時間ごと（面1で5秒、下限2秒）か、**画面の敵が全滅した瞬間**

---

## 8. 土の膜（重要）

掘り跡は升の内側12×12pxだけを抜くので、**隣り合う坑道の間に2pxの土の膜が残る**ことがある
（片方が後から掘られたとき）。この膜は**見た目だけでなく本物の壁**で、
升と升の境目ごとに「抜けているか」を持っている（`cell_link[]`）。

- 面の最初から掘れている升どうしは繋がっている扱い
- 後から抜けるのは、**自機の掘り跡が実際にその境目を跨いだときだけ**
- 敵はこれを歩いて抜けられない（透明化するしかない＝遅くなる）
- 自機は普通に掘って抜ける

**この仕組みが敵の圧を大きく下げている。** 実測で「敵が1升以内に居る時間」が 78% → 59%。

## 9. ボーナス

岩を2個割ると盤面中央に出現（10秒）。上を通ると取得。3種類:

| 種類 | 効果 | 出現率 |
|---|---|---|
| 得点 | 1000点 | 5/10 |
| 体温回復 | 体温を0に | 3/10 |
| 残機+1 | | 2/10 |

## 10. 得点

| 行為 | 点 |
|---|---|
| 土を1升掘る | 5 |
| 火薬を拾う | 10 |
| 黒ダイヤを割る | 50 |
| 黒ダイヤを採掘する | 200 |
| ボーナス | 1000 |
| 面クリア時の採掘率 | 1%あたり20 |
| 面クリア時の残ダイナマイト | 1本あたり100（**1本につき1回だけ**） |
| 敵を倒す | 同時に倒すほど倍率が上がる。落下岩は爆風の倍 |

## 12. 音

- **タイトル BGM**: Down in a Coal Mine（1872年、著作権切れ）。PSG3声
- **ゲーム BGM**: 常磐炭坑節。PSG3声（旋律／ベース／ノイズドラム）
- 効果音は ch C を一時的に奪って鳴らす（優先度つき）
  掘る／拾う／投げる／爆発／ミス／**つるはし（キン）**／投げられない／**破砕**
- PSG は矩形波固定。金属音はトーンとノイズを同じチャンネルに重ねて作っている

---

## 13. 演出

- 面の切り替えは**画面を消して（R#1 bit6）**パレット差し替えと描画を隠す（面1で1.12秒）
- 黒ダイヤが割れると**画面を縦に揺らす**（R#18、振幅2→1、約0.19秒）
- 面の開始で `STAGE n START` を1秒表示してから BGM とともに開始
- クリア時は自機も敵も停止 → ファンファーレ

## 16. 既知の弱点・気になっている点

**設計上の弱さ（相談したいのはここ）**

1. **敵を倒す動機が弱い。** 倒しても黒ダイヤは減らず、得点が入るだけ。
   しかも倒す手段（岩・ダイナマイト）はどちらも資源を消費する。
   **合理的には敵を無視して掘り続けるのが最適**になってしまう。
2. **岩とボーナスの立ち位置が薄い。** 爆風が地形を掘らなくなったので、
   ダイナマイトも岩も「対敵専用」で役割が重なっている。
   ボーナスは黒ダイヤに関係しないので寄り道の理由が弱い。
3. **爽快感が足りない。** プレイ時間の大半が「掘る」で、そこに報酬が薄い。
   炭層化と破砕演出を入れたが、まだ「溜めて一気に放出する」瞬間が少ない。
4. **序盤（面1〜7）が簡単すぎる**という体感がある。
5. **体温60秒**は、面が短くなったぶん緊張感が薄まっている可能性がある。

**仕様の一貫性が微妙な点**

6. **落下してきた岩は風呂を壊すが、ダイナマイトは壊さない。**
   当初は「岩やダイナマイトで破壊される」仕様だったが、ダイナマイトを投擲化して
   爆風が地形を壊さなくなった際、岩の側だけが残った。
7. 割れた黒ダイヤは**その升に入らないと採掘できない**（割った瞬間ではない）。
   敵に追われて割った直後に逃げると回収し損ねる。**これは意図した駆け引き**。
8. **地中を透明で移動している敵にはダイナマイトが当たらない**（坑道しか飛ばないため）。
   仕様としては筋が通っているが、遊ぶ側には分かりにくい。

**技術的な制約**

9. **ROM の固定領域（0x4000-0x9FFF の24KB）の空きが約1.5KB しかない。**
   ROM 容量自体は余っている（セグメント3が丸ごと空き、128KBへの拡張も可能）ので、
   機能を足すときは `art`／`music` の定数データをバンク側へ逃がす必要がある。
10. SDCC の警告110（`conditional flow changed by optimizer`）が `src/field.c` に1件出る。
    最適化器が条件分岐を組み替えたという情報提供のメッセージで、動作は検証済み。
