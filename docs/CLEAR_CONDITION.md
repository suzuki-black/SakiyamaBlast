# クリア条件の再設計 — 現状の問題と改善案

ゲームの根幹に関わる判断のための資料。**まだ何も変更していない。**
現状の仕様と、実際にコードから読み取れる数字、そこから見える問題、
そして改善案それぞれの得失をまとめる。

計測・計算はすべて 2026-08-27 時点のコード（`3dd5ff9`）に基づく。

---

## 1. 現状のシステム

### 1-1. クリア条件

```c
/* src/main.c:357 */
} else if (dug_pct >= WIN_PCT) {      /* WIN_PCT = 90 */
```

盤面 **16×11 = 176升** のうち **90% 以上を掘る**とクリア。
整数演算の都合で、実際に必要なのは **159升**（`159×100/176 = 90`）。

### 1-2. 盤面の数字

| 項目 | 値 | 出どころ |
|---|---|---|
| 盤面 | 16×11 = 176升（1升16px） | `COLS` `ROWS` |
| クリアに必要な掘削 | **159升** | `WIN_PCT 90` |
| 面開始時の既掘 | 16〜36升（面番号の形＋湧き出し口1升） | `carve_stage_number` |
| 実際に掘る升 | **123〜143升** | 上2つの差 |
| 掘削速度 | 40px/s（坑道は60px/s） | `SPD_DIG 8 / SPD_UNIT 12` |
| 火薬 | 10本/面（次の面へ持ち越し） | `POWDER_PER_STAGE 10` |
| ダイヤ | 土升の (面-1)×2 %。面15で40個 | `place_diamonds` |
| 岩 | 最大4個。2個割るとボーナス出現 | `ROCK_MAX` `ROCKS_PER_BONUS` |
| 敵 | 総数 4+面（上限19）／同時4体 | `quota_for_stage` |
| 体温 | 3600フレーム = **60秒**で上限 → 1ミス | `TEMP_MAX 240 × TEMP_TICK 15` |
| 風呂 | 1面に1個。**爆風で壊れると復活しない** | `bath_destroy_at` |

### 1-3. 1面でプレイヤーが実際にやること

1. 面番号の形に掘り抜かれた坑道から出発する
2. 土を掘る。**盤面の9割を掘るまで終わらない**
3. 60秒ごとに風呂へ戻って体温を下げる（1面で3〜5往復）
4. 火薬を拾ってダイナマイトを貯める
5. ダイヤに行き当たったら、そこはダイナマイトでしか壊せない
6. 敵をよける。岩で潰すかダイナマイトで吹き飛ばすかは任意

### 1-4. 各要素がクリアに寄与しているか

| 要素 | クリア条件への寄与 |
|---|---|
| 掘る | **これがすべて** |
| ダイナマイト | 面7以降のみ必須（ダイヤを壊さないと90%に届かないため） |
| ダイヤ | 障害物。壊さないと掘削率が頭打ちになる |
| 敵 | **寄与しない**（倒しても掘削率は上がらない。得点のみ） |
| 岩 | **寄与しない**（敵を潰す／ボーナスを出す） |
| 風呂・体温 | 寄与しない（失敗条件の側） |
| ボーナス | 寄与しない（得点・体温回復・残機） |

## 2. 問題点

### 2-1. 1面が長い（構造的な原因）

掘るべき升が 123〜143升、1升16px を 40px/s で掘るので、
**純粋に掘っている時間だけで最低 49〜57秒**。

これは「一切引き返さず、一度も無駄な移動をせず、敵にも邪魔されなかった場合」の
理論値であって、実際には

- 体温60秒ごとに風呂へ往復（1面で3〜5回）
- 掘り残した1升を拾いに戻る
- 敵をよけるための迂回

が乗る。実測の体感 **3〜5分** は計算と矛盾しない。15面で **1時間超**。

**根本原因は「盤面の9割を掘れ」という条件そのもの。** 掘る速度を上げても
盤面を狭くしても、比例して短くなるだけで作業感は消えない。

### 2-2. 掘ること自体が目的になっている

Dig Dug も Mr. Do! も、掘るのは**敵に近づく／逃げ道を作るための手段**で、
クリア条件は別にある（Dig Dug＝敵全滅、Mr. Do!＝チェリー全回収か敵全滅）。

本作は掘ることが目的なので、**敵は純粋な邪魔者**、岩とボーナスは寄り道、
ダイナマイトは面7以降の障害物撤去。目的に絡む要素が「掘る」しかない。

### 2-3. ダイナマイトの役割が面によって極端

必要な爆破回数を計算した結果（最善手を100回試行した中央値）:

| 面 | ダイヤ | 掘れる上限 | 壊すべきダイヤ | 必要な爆破回数 |
|---|---|---|---|---|
| 1〜6 | 0〜16 | 160〜176 | **0** | **0回** |
| 7 | 20 | 156 | 3 | 1〜2回 |
| 9 | 26 | 150 | 9 | 3〜5回 |
| 11 | 29 | 147 | 12 | 3〜6回 |
| 13 | 35 | 141 | 18 | 6〜9回 |
| 15 | 40 | 136 | 23 | **7〜10回** |

- **面1〜6はダイナマイトを1本も使わずにクリアできる。** 序盤は掘るだけ。
- 上の数字は「十字5升でいちばん多く壊せる位置を毎回選んだ場合」。人間の実際の
  狙いだと1発あたり2個前後になるので、**面15は11発前後**必要。**火薬10本では足りない。**
- 破綻していないのは持ち越しがあるから。つまり**序盤で溜めていないと後半で詰む**、
  という遊ぶ前には分からない設計になっている。

### 2-4. 風呂を爆破すると事実上の詰み

風呂は爆風で壊れ、その面では復活しない（`bath_destroy_at` → `bath_on = 0`）。
壊した瞬間から**残り最大60秒**で9割掘り切らないとミス。
後半ほど爆破回数が増えるので、事故の確率も上がる。警告も表示もない。

### 2-5. 敵を倒す動機がない

倒しても掘削率は上がらず、得点が入るだけ。しかも倒す手段は
「岩で潰す」「ダイナマイトで吹き飛ばす」の2つで、どちらも**クリアに必要な資源を消費する**。
合理的には**敵を無視して掘り続けるのが最適**になる。

### 2-6. タイトルとゲーム内容が噛み合っていない

タイトルは「**クロダイヤ 〜先山丹野3時〜**」。しかしクロダイヤ（ダイヤブロック）は
**掘削率を邪魔する障害物**でしかない。プレイヤーの目的は「盤面を9割耕すこと」であって
黒いダイヤを掘り出すことではない。

### 2-7. 良くできている点（壊さないように）

問題ばかりではないので、変更で失いたくないものも挙げておく。

- **HUD の採掘率バーに90%のマーカーが出ている** — 進捗は数字で見える（`draw_bar`）
- **体温メーターと風呂の往復**は、掘りっぱなしにさせない良いリズムを作っている
- **岩で敵を押し潰せる**（横滑りでも判定あり）— ダイナマイトを節約する遊びになっている
- **火薬の持ち越し**は「今使うか、次に取っておくか」という判断を生んでいる
- **岩2個でボーナス**は Dig Dug の野菜と同じ、寄り道の動機になっている

## 3. 改善案

### 案A: クロダイヤを全部掘り出す

**クリア条件**: 面に置かれたクロダイヤを**全部ダイナマイトで割る**。掘削率の条件は撤廃。
ダイヤは面ごとに3〜8個程度に減らし、HUD に残数を出す。

| | |
|---|---|
| **メリット** | ・**タイトルとゲームの目的が一致する**。「クロダイヤを掘り出す」がそのまま勝利条件<br>・**ダイナマイトが全面で主役になる**。面1から使う理由ができ、2-3 の「序盤は掘るだけ」が消える<br>・**掘るのが手段に降格する**。盤面の9割を耕す必要がなくなり、面が劇的に短くなる<br>・残数表示で目標が具体的になる（「あと3個」）<br>・実装が小さい。判定を差し替えて配置数の表を足すだけ |
| **デメリット** | ・**掘る楽しさが薄くなる**。掘削は移動手段になり、盤面を耕す達成感が消える<br>・**ダイヤへの最短経路を掘るだけになりがち**。現状ダイヤは最初から見えているので、経路が一意に決まり単調になる恐れ<br>・**火薬10本と必要爆破数の関係がシビアになる**。火薬を取り逃すと物理的に詰む → 詰み検出か救済が要る<br>・岩とボーナスの役割がさらに薄くなる<br>・敵を倒す動機は依然としてない（2-5 は解決しない） |
| **想定プレイ時間** | 1面 1〜2分（ダイヤ5個で移動距離60〜100升と仮定） |
| **実装コスト** | 小（判定1箇所＋配置数の表＋HUD の残数表示） |

**変種 A': クリアはダイヤ、掘削率は得点ボーナス。**
クリア条件はダイヤ全回収にしつつ、面クリア時に掘削率×点数を加算する。
掘る楽しさを「やり込み」として残せる。デメリットの1つ目をほぼ潰せるので、
**Aを採るならこの形を推す。**

---

### 案B: 掘り出したクロダイヤを坑口へ運ぶ

**クリア条件**: ダイヤを割ると原石が落ちる。それを拾って**出発点（坑口）まで運ぶ**。
同時に持てるのは3個まで。ミスすると持っていた分をその場に落とす。

| | |
|---|---|
| **メリット** | ・**深く潜って戻るリズム**が生まれる。炭鉱ものとして絵になる<br>・**体温メーターと噛み合う**。帰り道に風呂があるので、往復が「面倒な作業」から「設計されたリズム」になる<br>・持てる数の上限が「もう1個取りに行くか、いま戻るか」という判断を作る<br>・ミスで落とすので、**敵をよける動機が強くなる**（2-5 に部分的に効く） |
| **デメリット** | ・**往復ぶん1面が長くなる**。2-1（面が長い）を悪化させる方向<br>・ミスで原石を落とす仕様は**理不尽に感じられやすい**。特に運搬中に湧いた敵に当たると腹が立つ<br>・実装が重い（原石オブジェクト、所持数、落下、HUD、坑口の判定）<br>・スプライト面を追加で消費する可能性 |
| **想定プレイ時間** | 1面 2〜3分 |
| **実装コスト** | 中〜大 |

### 案C: 落盤から逃げる

**クリア条件**: 規定量を掘る（現状どおり、ただし量は減らす）。
そのかわり一定時間で**天井から岩が降り始め**、潰されたらミス。

| | |
|---|---|
| **メリット** | ・炭鉱ものとして最も本物らしい危険（落盤は実際の坑内事故の筆頭）<br>・既存の岩の落下コードを流用できる<br>・「急がされる」ので、掘りの作業感が緊張感に変わる |
| **デメリット** | ・**これは失敗条件であってクリア条件ではない**。2-2（掘ることが目的）は解決しない<br>・**体温メーターと役割が重複する**。タイマーが2本になり、どちらも「時間切れでミス」<br>・降ってくる岩は**理不尽に見えやすい**。回避可能に設計するのが難しい<br>・盤面が狭い（16×11）ので逃げ場が少ない |
| **想定プレイ時間** | 1面 1〜3分（制限次第） |
| **実装コスト** | 中 |

### 案D: 坑木（支柱）を立てて回る

**クリア条件**: 面ごとに指定された升目に**坑木を立てる**。坑木はアイテムとして落ちている。

| | |
|---|---|
| **メリット** | ・目標が明快で、残数も出せる<br>・立てる場所を固定にできるので、**運によるブレが無い**（案Aのデメリットを避けられる）<br>・炭鉱の作業としては正確（坑木は実際の支保工） |
| **デメリット** | ・**お使い感が強い**。掘る面白さとも爆破の爽快感とも噛み合わない<br>・**ダイナマイトの役割が無くなる**（2-3 が悪化）<br>・新しい絵（坑木）とアイテム管理が必要<br>・タイトルとの関係はむしろ薄くなる |
| **想定プレイ時間** | 1面 1〜2分 |
| **実装コスト** | 中 |

### 案E: 現状のまま数字だけ調整する

**クリア条件**: 変更なし。`WIN_PCT` を 90 → 70〜75 に下げ、ダイヤの比率を下げる。

| | |
|---|---|
| **メリット** | ・**リスクゼロ**。今日中に終わる<br>・いま良くできている点（2-7）を一切壊さない<br>・数字を振って体感を確かめる作業に集中できる |

## 5. 推薦

**案A'（クロダイヤ全回収＋掘削率は得点ボーナス）を推す。**

理由:

1. **問題の根に当たっている。** 面が長いのも、序盤にダイナマイトを使わないのも、
   タイトルと内容が乖離しているのも、すべて「掘削率がクリア条件」から来ている。
   Aはそこを直接差し替える。
2. **実装が小さいので、遊んでみて駄目なら戻せる。** 判定は1箇所、配置数は表1つ。
   BやCは作り込んでから「違った」となると痛い。
3. **掘削率を得点に回すことで、いま良くできている部分を捨てずに済む。**
   耕したい人は耕せばスコアが伸びる。

ただし **A単独では 2-5（敵を倒す動機がない）は解決しない。** ここは別途、
たとえば「敵を倒すと火薬を落とす」のような形で手当てするのが自然だと思う。
案Aを入れたあとで様子を見て決めればよい。

## 6. 決める必要があること

案Aを採る場合に決めるべき点:

1. **ダイヤの配置数** — 面ごとに何個か。3個から始めて面15で8個、など
2. **ダイヤは最初から見えるか** — 見えると経路が一意に決まって単調になる。
   隣接するまで土に隠す案もあるが、計画が立てられなくなる
3. **火薬の本数** — ダイヤ数に対して何本配るか。詰まないための下限をどう保証するか
4. **詰んだときの救済** — 火薬を使い切ってダイヤが残った場合どうするか
   （面をやり直す／火薬を追加で湧かせる／自爆で仕切り直す）
5. **掘削率ボーナスの点数** — 1%あたり何点か
6. **体温と風呂はそのままでよいか** — 面が短くなると60秒の意味が変わる。
   風呂への往復が1面1回で済むなら、体温メーターの緊張感は薄まる

## 付録: 計算の再現方法

本文の数字は次で再現できる。

- クリアに必要な升数: `min(n for n in range(177) if n*100//176 >= 90)` → 159
- 面ごとのダイヤ数: `ceil(dirt * (stage-1)*2 / 100)`（`dirt = 176 - 既掘`）
- 必要な爆破回数: ダイヤを盤面へランダムに置き、十字5升で最も多く壊せる中心を
  貪欲に選ぶ試行を100回。詳細は本文の表を参照
- 掘削時間: `升数 × 16px ÷ 40px/s`
- 体温の猶予: `TEMP_MAX × TEMP_TICK ÷ 60fps` = `240 × 15 ÷ 60` = 60秒
