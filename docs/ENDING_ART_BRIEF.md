# エンディング一枚絵の指示書（表／裏）

表面・裏面のエンディングに入れる一枚絵、2枚ぶんの指示書。**絵は Microsoft Copilot に
描かせ、こちらで減色して ROM へ入れる**（タイトル画像と同じ作り方）。

**指示書は1枚ずつ渡せるように、2つに分けて書いてある。** 共通の約束は両方に
書き写してあるので、どちらか一方だけをそのまま貼って使える。

史実の裏付けは `docs/HISTORY.md` §5.6。**裏面の場面を「大浴場」と書いてはいけない
理由もそこにある**（男女別なので家族3人を並べられない）。

## 指示書① 表面エンディング ──「おかえりなさい」

**最終形**: MSX2 SCREEN 5 / **256×212 画素・16色**。**入稿は 1536×1024 の PNG**
（こちらで縮小・減色する）。

**守ってほしいこと**

- **大きな面で作る。** 細い線・細かい模様・小さな顔の描き込みは、縮めると消える
- **グラデーションに頼らない。** 階調は3〜4段で割り切れる形に
- **主役は中央寄りに。** 左右の端は切り落とす可能性がある
- **文字を入れない。** 看板・ロゴ・字幕・透かし、いっさい不要
- **色は明度で差を付ける。** 色相だけが違う組み合わせで主従を分けない。
  白黒にしても構図が読めること（**作者は色弱**）
- **画風**: 1950〜60年代の日本の生活を描いた、輪郭のはっきりした落ち着いた塗り。誇張しない

**場面**: 昭和30年代後半、常磐炭鉱の炭鉱長屋の茶の間。夜。一日の仕事を終えた先山が
家へ帰ってきたところ。

- **父** 40代。坑内から帰ったばかりで顔と手に炭塵が残っている。作業着。入口の框のあたり
- **妻** ちゃぶ台のそばで、こちらを向いて迎えている
- **娘** 小学生くらい。父のほうを向いている
- **ちゃぶ台** 妻の手料理、**刺身の盛り合わせ**、**徳利とお猪口**
- **テレビ** 買ったばかりの白黒テレビ。木の箱に収まった脚付きの型。画面に**大相撲**
- 裸電球が1つ。畳、障子

**いちばん大事なこと**: **光源はテレビと裸電球の2つだけ。** 部屋は暗く、その2つの光が
家族を照らしている。「坑内で掘った石炭が町の灯りになり、この茶の間を照らしている」
という文章の受け皿なので、**光が主役**。明暗の差を強く。三人の顔がはっきり見えること。

## 指示書② 裏面エンディング ──「同じ湯だった」

**最終形**: MSX2 SCREEN 5 / **256×212 画素・16色**。**入稿は 1536×1024 の PNG**
（こちらで縮小・減色する）。

**守ってほしいこと**

- **大きな面で作る。** 細い線・細かい模様・小さな顔の描き込みは、縮めると消える
- **グラデーションに頼らない。** 階調は3〜4段で割り切れる形に
- **主役は中央寄りに。** 左右の端は切り落とす可能性がある
- **文字を入れない。** 看板・ロゴ・字幕・透かし、いっさい不要
- **色は明度で差を付ける。** 色相だけが違う組み合わせで主従を分けない。
  白黒にしても構図が読めること（**作者は色弱**）
- **画風**: 1950〜60年代の日本の生活を描いた、輪郭のはっきりした落ち着いた塗り。誇張しない

**場面**: 1966年以降。**炭鉱の温泉水で温めた、巨大な屋内ドームの温水プール。**昼下がり。
炭鉱が閉じ、坑内で坑夫を苦しめていた湯が、地上へ汲み上げられて人を楽しませる湯に
なった、という常磐の実話が土台（`docs/HISTORY.md` §5.6）。

- **ここは風呂ではなくプール。** 全員**1960年代の水着**（女性はワンピース型、
  男性はトランクス型）。だから**家族3人が同じ水の中にいられる**
- **父** 指示書①と同じ人物。50代後半〜60代。**水の中に腰から胸まで浸かっている。
  笑っていない。何も言っていない顔**
- **妻** 同じく年を取っている。水の中か、プールの縁に腰かけて足を入れている
- **娘** ①から十数年経って、若い女性
- **背景** **格納庫のように巨大な屋内ドーム**。高い屋根、大きな窓。**本物のヤシの木と
  バナナの木**が水辺に植わっている。**まっすぐな滑り台**を奥に入れてよい。湯気が立っている
- 他の客が数人いてよい（顔は描き込まない。人影程度）

**いちばん大事なこと**: **①と対になる絵。** ①が「暗い部屋の中の2つの光」なら、
こちらは**ひらけた明るさ**。同じ家族が、同じ湯の中で、別の場所にいる。**湯気を入れる**
（坑内の熱水と同じものだと分かる手がかり）。窓から光がたっぷり入る。

**任意**: 窓の外を**雪景色**にすると、「真冬に常夏」というこの施設の値打ちがそのまま
絵になる（1月開業の施設）。中の明るさと外の白さで明度の差も付く。

**必ず守ること**: 実在して現在も営業している施設が元。**宣伝に見える絵にしない。**

- **施設名・ロゴ・看板・のれん・パンフレットの類を一切描かない**
- フラダンスのショーや舞台は描かない（プールの場面にする）
- 建物の外観や特定の建築を再現しない。**当時の南国風の屋内温水プール**という
  一般的な描き方にとどめる
- 裸の入浴場面は描かない（**別の建物で、しかも男女別**。この場面ではない）

## 受け取ったあとの作業（**済み。2026-11-16**）

絵は1回目で両方とも通った。やったことは次の4つ。

1. `tools/png2sc5.py` で 256×212・16色へ落とす（タイトル画像と同じ道具）。
   **`--dither` を付けた。** 無しと見比べて、父の顔の階調と水面が目に見えて良い
   （どちらも中間調が主役の絵なので効く）
2. **ROM を 128KB → 256KB へ増やした。** 16セグメントは全部埋まっていて、
   一枚絵1枚で4セグメント（27,136バイト）要る。表が seg16〜19、裏が seg20〜23
3. エンディングの頭で一枚絵を出し、キー待ちのあとロールを流す
   （`ending_pic()` ＋ `main.c` の `ST_ENDPIC`）。**20秒で自動的にロールへ進む** ——
   絵の上に案内を出していないので、押さないと止まったままになるのを避けるため
4. openMSX で実際に表示して確認した。**白黒にしても構図が読める**こと、
   ロールへ移るときに `set_game_palette()` でゲームのパレットへ戻ることを実測

**何枚か候補を出してもらって、縮小してから選ぶ。** 1536×1024 で良く見えても、
256×212 の16色にすると別物になることがある（今回は1回目で通った）。

## 書き直した経緯（2026-11-15）

**②をはじめ「椰子の木のある大浴場」として書いていたのは間違いだった。** 作者が
「ハワイアンセンターって家族風呂ありました？ 男女分かれていたような」と気付いて
調べ直し、**開業時の目玉は大浴場ではなく大ドームの温水プール**で、家族が一緒に
いられるのは水着のプールだから、と分かった。裏付けと出典は `docs/HISTORY.md` §5.6。

**「ローマ風呂」と書いた箇所もあったが、この施設には無い**（別の施設との混同）。

**教訓: 実在の施設を舞台にするなら、建物の中の決まり（男女別かどうか）まで
確かめてから絵を頼むこと。** 絵が仕上がってから気付くと描き直しになる。
